# AI 助手

> 右栏下半部分的第二种面孔：能**看当前这张图**、能查词库、能把改动摆成一张提案卡片，
> 等你点「应用」才写进提示词。开关在「设置 → AI 助手」。

## 打开与关闭

| | |
|---|---|
| 打开 | 设置 → **AI 助手** → 勾「打开 AI 助手面板」 |
| 位置 | 右栏下半部分（原来是「中文描述 → 英文自然语言」那一格） |
| 关掉 | 取消勾选 —— 右栏**退回原来的翻译器**，一切照旧 |

> **翻译器没有被删掉。** 它是四轮实测调出来的确定性转换（长度跟输入走、
> 方向词不许丢、不许加质量词），助手面板换来的是能读图、能一次提出多项改动，
> 代价是不再逐字可复现。两条路各有各的用处，所以是两个面板，不是一个替换一个。

## 两个模式里的区别

| | 标注模式 | 写标签模式 |
|---|---|---|
| 有图吗 | 有，默认**带上当前这张图**（可取消勾选） | 没有图，勾选框自动灰掉 |
| 它做什么 | 看画面 → 提出该加的标签 + 一段散文 | 照你的描述 → 规范化写法、补标签、把不是标签的部分写成散文 |
| 改动落到哪 | 当前这张图的 caption | 当前这条草稿 |

## 怎么用

1. 在输入框里写一句话，`Ctrl+Enter` 发送（或点「发送」）。单个 `Enter` 是换行。
2. 等它查完词库（状态栏会显示用了几轮、几秒、查过多少条）。
3. 它会把结果摆成一张**提案卡片**：

| 卡片上的东西 | 你可以怎么做 |
|---|---|
| 一串标签，每个后面跟着词库里的中文释义 | 点单个 `＋` 只加这一个；或点底下的「应用（N 个标签 + 散文）」一次全加 |
| 一段英文散文，标着「追加」或「替换」 | 跟着「应用」一起落进提示词；不想用它就只点单标签的 `＋` |
| 橙色的标签 | **词库查不到这个词**。仍然可以加——词库不是全集 |

4. **只有点了「应用」才会写进提示词。** 在那之前它一个字符都没动过你的文档。
5. 应用是一次动作 = **一个撤销点**：按一次 `Ctrl+Z` 全部退掉。

## 它被要求遵守的几条规矩

这些不是"提示词里随便写写"，是它的行为约束（写进系统提示，并有回归测试钉着）：

- **标签名必须先查词库再写。** Danbooru 标签是精确字符串，`blush` 和 `blushing`
  是两个不同的东西（后者根本不存在）。凭记忆写出来的标签名多半加进去不生效。
- **没有对应标签的概念，写成英文散文，而不是硬造一个标签。** 比如"猫趴在她肩上"
  这种**关系**、或者你自造的名字，都属于散文该管的部分。
- **但"词库查不到"不等于"该改成散文"**：`@syrstyle`、`2 fingers`、`bangs` 词库都不认，
  它们仍然留在标签里。画师触发词不带 `@` 效果非常弱，被"顺成一句话"就废了。
- **不编。** 带图时只写它真的看得见的东西；用户没说的不补。
  以前翻译器就因为"至少写两句"编造过长度、蓬松度、审美评价，那条教训同样适用在这里。
- **质量词、分数、安全词不擅自加**（`masterpiece`、`score_7`、`safe` 那几类），
  除非你明确要求——它们由程序这边单独管。

## 花费

| 项目 | 量级 |
|---|---|
| 一次发送 | 1–4 次请求（每次查库算一轮，提案单独一轮） |
| 一张图 | 先缩到长边 1024 的 JPEG（约 65–150 KB），约 850 token |
| 状态栏 | 会写明这次用了几轮、多少秒、查过多少条 |

图只发给你**自己配置的那个接口地址**，不会上传到别处（是内联在请求里的）。
如果你的接口或模型不吃图片输入，程序会**如实报错**，不会静默退回"凭空描述"——
那时可以取消「带当前图片」，或者换一个支持读图的模型。

## 边界

- **换图片 / 换草稿会清空对话。** 历史里带着上一张图的画面，跨文档继续问会让它把
  A 图的内容说到 B 图上。
- **对话不跨重启。** 关掉程序就没了。
- **它不会自己保存。** 应用之后要落盘仍然按 `Ctrl+S`（标注模式写回 `.txt`，
  写标签模式复制走并入库）。
- **联网搜索是个可选工具**（设置 → 联网搜索）。开了它才能查"这个词什么意思"，
  没开时不会下发这个工具，模型也不会去试。
