# AI 助手

> 右栏下半部分的第二种面孔：能**看当前这张图**、能查词库、能把改动摆成一张提案卡片，
> 等你点「应用」才写进提示词。开关在「设置 → AI 助手」。

## 打开与关闭

| | |
|---|---|
| 打开 | 设置 → **AI 助手** → 勾「打开 AI 助手面板」 |
| 位置 | 右栏下半部分（原来是「中文描述 → 英文自然语言」那一格） |
| 关掉 | 取消勾选 —— 右栏**退回原来的翻译器**，一切照旧 |

> **翻译器没有被删掉。** 它是四轮实测调出来的确定性转换（长度跟输入走、
> 方向词不许丢、不许加质量词），助手面板换来的是能读图、能一次提出多项改动，
> 代价是不再逐字可复现。两条路各有各的用处，所以是两个面板，不是一个替换一个。

## 两个模式里的区别

| | 标注模式 | 写标签模式 |
|---|---|---|
| 有图吗 | 有，默认**带上当前这张图**（可取消勾选） | 没有图，勾选框自动灰掉 |
| 它做什么 | 看画面 → 提出该加的标签 + 一段散文 | 照你的描述 → 规范化写法、补标签、把不是标签的部分写成散文 |
| 改动落到哪 | 当前这张图的 caption | 当前这条草稿 |

## 在面板里直接换模型

标题旁边那个按钮显示的是「**站点名 · 档位**」。点它可以：

- 换**站点**（一整套「地址 + 密钥 + 模型名 + 推理档位」一起换过去）
- 换**推理档位**

选完**立刻生效**，不用打开设置、也不用重启。改完按钮上的字就跟着变，所以当前用的是谁一直看得见。

放在这里是因为"这个模型答得不好，换一个"或"忘了切到能读图的那个"往往发生在对话中途；要为此打开设置、翻两页、点保存，代价大到用户干脆不换。

> 站点本身在**设置 → 模型接口**里增删改（见[模型接口](05-translation.md#配置模型接口)）。面板里这个选择器只做切换，不做编辑——编辑要填地址和密钥，那不是个适合塞进弹出层的事。

## 看不清的细节：它会自己放大

整张图是**缩到长边 1024** 再发过去的（4000×6500 的照片变成 630×1024），
所以画面上很小的东西——袖口的蕾丝、眼睛里的高光、背景上的一行字——模型在原图里
是真的看不清。它现在有两个工具专门处理这件事：

| 工具 | 干什么 | 花多少 |
|---|---|---|
| 问图像信息 | 拿到原图尺寸、EXIF 方向、文件大小、这次被缩到多小 | **不花钱**（纯文字） |
| 放大一块 | 把指定区域按原分辨率裁出来再发给它看 | 每张约 850 token |

用法上你什么都不用做：问它一个需要看清细节的问题，它会自己决定先问信息、
再要一块放大图。它会说清要的是哪一块（坐标一律是 0–1 的相对位置，例如
"左上角 20%×30% 那一块"），也能按网格把整张图切成最多 3×3 = 9 块逐块看。

> **放大图是用完即焚的。** 它只活在这一次对话的请求里：不落盘、不进对话历史，
> 下一次要看就再裁一次。所以关掉程序再打开，历史还在，但那些放大图不在了。
>
> **额度是有限的**：一次对话最多 12 张放大图（3×3 就用掉 9 张）。用光了它会说明，
> 然后拿已经看到的作答——而不是悄悄少看几块。这个上限是必要的，因为每张图都算 token，
> 而且**插进对话的图在后面每一轮请求里都会重新发一遍**。
>
> **「带当前图片」没勾时，放大也不会发生。** 放大的图只能靠"额外发一条带图的消息"
> 送出去，而那个开关是你明确关掉的，程序不会绕过它。

## 怎么用

1. 在输入框里写一句话，`Ctrl+Enter` 发送（或点「发送」）。单个 `Enter` 是换行。
2. 等它查完词库（状态栏会显示用了几轮、几秒、查过多少条）。
3. 它会把结果摆成一张**提案卡片**：

| 卡片上的东西 | 你可以怎么做 |
|---|---|
| 一串标签，每个后面跟着词库里的中文释义 | 点单个 `＋` 只加这一个；或点底下的「应用（…）」一次全加 |
| 红色的 `－ 标签`（如果它要删） | 跟着「应用」一起删掉。**看清楚再点**——删除同样不可逆（只能整个 Ctrl+Z 退） |
| 一段英文散文，标着「追加」或「替换」 | 跟着「应用」一起落进提示词；不想用它就只点单标签的 `＋` |
| 橙色的标签 | **词库查不到这个词**。仍然可以加——词库不是全集 |

4. **只有点了「应用」才会写进提示词。** 在那之前它一个字符都没动过你的文档。
5. 应用是一次动作 = **一个撤销点**：按一次 `Ctrl+Z` 全部退掉。

> **"写进提示词"不等于"存进文件"。** 应用改的是编辑器里那一段，盘上的 `.txt`
> 要按 `Ctrl+S` 才写（开不开「完全权限」都一样）。所以点完应用记得保存——
> 否则切走这张图时会按你眼前的内容重写文件，看似"没生效"的其实是没保存。

## 覆盖标签

说「把标签覆盖成 A、B、C」时，它会：
1. 先查出这张图**现在有哪些标签**（不是猜，是真的读出来）；
2. 把不该留的列进删除、该有的放进新增；
3. 卡片上分成两段显示：红色的是**将删除**，普通的是**将添加**，「应用」按钮上两个数都写出来。

> 这条通道是补上的。此前它只有"添加"一种动作，于是你说"覆盖"时它**只能往里加**，
> 却在回复里说"已替换"——标签列表看着没变，而它坚称做了。现在如果它说要删，
> 卡片上一定列得出来；没列出来的就是没删。
>
> 顺带：**再让它覆盖一次同样的内容，它可能什么都不做**（`tags+=0 tags-=0`）——
> 那是因为上一次已经覆盖好了，不是失灵。

## 它被要求遵守的几条规矩

这些不是"提示词里随便写写"，是它的行为约束（写进系统提示，并有回归测试钉着）：

- **标签名必须先查词库再写。** Danbooru 标签是精确字符串，`blush` 和 `blushing`
  是两个不同的东西（后者根本不存在）。凭记忆写出来的标签名多半加进去不生效。
- **没有对应标签的概念，写成英文散文，而不是硬造一个标签。** 比如"猫趴在她肩上"
  这种**关系**、或者你自造的名字，都属于散文该管的部分。
- **但"词库查不到"不等于"该改成散文"**：`@syrstyle`、`2 fingers`、`bangs` 词库都不认，
  它们仍然留在标签里。画师触发词不带 `@` 效果非常弱，被"顺成一句话"就废了。
- **不编。** 带图时只写它真的看得见的东西；用户没说的不补。
  以前翻译器就因为"至少写两句"编造过长度、蓬松度、审美评价，那条教训同样适用在这里。
- **质量词、分数、安全词不擅自加**（`masterpiece`、`score_7`、`safe` 那几类），
  除非你明确要求——它们由程序这边单独管。

## 花费

| 项目 | 量级 |
|---|---|
| 一次发送 | 1–4 次请求（每次查库算一轮，提案单独一轮） |
| 一张图 | 先缩到长边 1024 的 JPEG（约 65–150 KB），约 850 token |
| 一张放大图 | 同上（按原分辨率裁出来再缩到 1024），约 850 token；一次对话最多 12 张 |
| 状态栏 | 会写明这次用了几轮、多少秒、查过多少条 |

图只发给你**自己配置的那个接口地址**，不会上传到别处（是内联在请求里的）。

**能不能带图，程序是问服务端要的答案，不是猜的。** OpenAI 兼容的云服务会在
`GET /models` 里直接报能力（`input_modalities` / `context_window` /
`max_output_tokens` / `effort`），设置里「获取列表」之后那行提示就会写出来，例如：

> 当前「deepseek-v4-pro」：DeepSeek-V4-Pro · 上下文 1048576 · 输出上限 393216 ·
> **仅文本输入** · 思考 low/high/max（默认 high）

服务端**明确**说过某个模型只吃文本时，「带当前图片」会自动灰掉并说明原因，
不会白白发一次注定失败的请求。这一条只在服务端真的报了的时候生效——本地
llama-server 之类不报这个字段，程序一律按"可以带图"放行，不会把能用的配置判死。

## 边界

- **换图片 / 换草稿不会清空对话**，但历史里带着上一张图的画面，所以换图之后它的回答
  可能把两张图说混——问的时候提一句"这是另一张"最保险。
- **对话会存下来**（`%LocalAppData%\AnimaCaptioner\` 下的对话文件），关掉程序再打开还在；
  只有「清空对话」按钮会清。**但放大出来的那些图不存**，它们只活在当次请求里。
- **它不会自己保存。** 应用之后要落盘仍然按 `Ctrl+S`（标注模式写回 `.txt`，
  写标签模式复制走并入库）。
- **联网搜索是个可选工具**（设置 → 联网搜索）。开了它才能查"这个词什么意思"，
  没开时不会下发这个工具，模型也不会去试。
