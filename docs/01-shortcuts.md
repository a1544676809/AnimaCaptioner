# 快捷键

> 全部快捷键一览。表格里的组合键都可以直接用。

## 文件与导航

| 快捷键 | 作用 |
|---|---|
| `Ctrl+O` | 打开训练集目录（标注模式） |
| `Ctrl+S` | **主操作**：标注模式 = 保存当前 caption；写标签模式 = 复制整行提示词 |
| `F5` | 重新载入词库与训练集 |
| `Alt+←` / `Alt+→` | 上一张 / 下一张（标注模式） |
| `Ctrl+→` | 跳到下一个未标注的图片（标注模式） |

## 模式

| 快捷键 | 作用 |
|---|---|
| `Ctrl+M` | 在标注模式与写标签模式之间切换 |
| `Ctrl+N` | 新建提示词（写标签模式；起点是官方推荐前缀） |

> 「保存到提示词库」和「按热度自动排段内顺序」没有快捷键，只在菜单里。
> `Ctrl+S` 在写标签模式下本身就是复制，而复制会自动把这条记进提示词库，
> 所以日常不需要单独点「保存到提示词库」。详见 [写标签模式](11-write-tag-mode.md)。

## 撤销与重做

| 快捷键 | 作用 |
|---|---|
| `Ctrl+Z` | 撤销上一步（标签与散文的改动） |
| `Ctrl+Y` | 重做 |

撤销覆盖：添加、删除、上移/下移、拖动排序、就地改名、粘贴、翻译/规范化、
规整大类顺序、按热度自动排、翻译散文、清空提示词。

> **撤销只改内存，不写文件。** 撤销之后要落盘仍然得按保存（标注模式 `Ctrl+S`
> 写回 `.txt`，写标签模式 `Ctrl+S` 复制走并入库）——否则撤销会变成一次悄悄的写盘。
>
> **换图片、换提示词会清空历史。** 撤销点里存的是上一份文档的标签，跨文档撤销
> 会让上一张图的标签出现在当前这份里。
>
> **什么时候 `Ctrl+Z` 不归这里**：焦点在提示词原文框、中文描述框或行内编辑框里时，
> `Ctrl+Z` 是那些输入框**自己的**撤销。焦点在「添加标签」框里、而框是空的时
> （刚按过回车就是这样），它归标签历史——那正是最想反悔的时刻。
>
> 快捷键没生效时用菜单「编辑 → 撤销/重做」，那里会写明下一步退掉的是哪个操作
> （例如「撤销（添加标签）」）。步数上限在「设置 → 编辑 → 最大撤销步数」，
> 默认 100，填 0 关闭撤销。

## 标签编辑

| 快捷键 | 作用 |
|---|---|
| `Ctrl+↑` / `Ctrl+↓` | 标签上移 / 下移（只在本大类内部） |
| `Ctrl+Shift+S` | 规整大类顺序 |
| `Ctrl+Shift+T` | 模型翻译：给缺中文的标签补释义 |
| `Delete` | 删除选中的标签 |
| `F2` | 就地编辑选中的标签 |
| `Ctrl+C` / `Ctrl+V` | 复制选中标签 / 把剪贴板解析成标签追加 |
| `右键` | 打开该行的功能菜单（复制、粘贴、编辑、翻译、模型翻译、移动、删除、校验） |
| `双击标签行` | 就地编辑该标签 |
| `空格` | 列表有焦点时打开预览 |

> **焦点在输入框里时，这些键归输入框自己。** 提示词框、中文描述框或行内编辑框
> 拿到焦点时，`Del`、`Ctrl+C/V`、`Ctrl+↑/↓`、`Ctrl+Z/Y` 都不作用于标签——
> 否则在提示词里按 `Del` 会连带删掉一个标签。这一点是刻意的，不是漏了。
> 其中 `Del`/`Ctrl+C/V`/`Ctrl+↑/↓` 只在**标签列表有焦点**时才作用于标签；
> `Ctrl+Z/Y` 的适用范围更宽，见上面「撤销与重做」。

> **移动标签时列表会跟着走。** 上移/下移只让那一个标签在段内换位，列表的滚动
> 位置不动——视线不会被打回列表开头。它被移到视口上/下边缘之外时，列表会跟着
> 翻一页，让它停在最上（或最下）一行，始终看得见。换图片时才会回到顶部
> （另一张图 = 另一份内容）。

## 输入框补全（添加标签 / 就地编辑）

两个输入框用法完全一样：打字时下拉列表自动展开，`Tab` 补全。

| 按键 | 作用 |
|---|---|
| `Tab` | 补成第一个候选；再按一次切下一个 |
| `Shift+Tab` | 往回切 |
| `Enter` | **添加**（添加框）/ **提交改名**（就地编辑） |
| `Esc` | 先关候选列表；列表已关时（就地编辑）才取消整次编辑 |
| 点候选 | 直接采用它 |

几条刻意定下的规矩：

- **`Tab` 循环的就是下拉列表里看得见的那几个**，不会跳到列表外的东西上。
  当前在第几格由状态栏说明（`补全 2/12：…`）。
- **按下 `Tab` 之后框里是什么，`Enter` 加进去的就是什么**——包括 `Tab` 循环到
  第 3 格再回车这种情况，不会去取列表里高亮的那一项。
- **一个已经合法的标签，第一次按 `Tab` 不会把它换掉。** 只会在状态栏报
  `补全 1/7`；再按一次才开始往后切。词库不认识的写法同理（只提示，不动它）。
- **中文打到一半也补得动**：`双马` → `twintails`（按中文释义的前缀匹配，
  比"包含匹配"更贴近你想打的那个词）。英文前缀同理：`twint` → `twintails`。
- **候选都是"回车能原样存下去"的形式**：词库会把退役名重定向到正典名
  （`china dress` → `qipao`），候选列表里显示的是后者——框里写什么，存的就是什么。
- 空输入框里按 `Tab` 仍然是正常的焦点切换，不会被这里吃掉。

## 就地编辑标签

双击一个标签（或选中后按 `F2`）它就变成输入框：

| 操作 | 结果 |
|---|---|
| `Enter` | 提交 |
| `Esc` | 先关候选列表；再按一次取消编辑，保持原值 |
| `Tab` / `Shift+Tab` | 补全候选（同上） |
| 点别处（失焦） | 提交 |

输入中文也可以（`仰视` → `from below`），会走和「添加标签」同一套词库解析。
改完名字会按大类重新归位，段内相对次序不变。

| 情况 | 行为 |
|---|---|
| 词库认得 | 换成规范形式，并在状态栏说明依据（Anima 索引 / 旧别名 / 人工词表…） |
| 词库不认得 | **原样保留**，只提示"不在任何索引中"——词库不是全集，静默改掉等于偷改训练集 |
| 规范形式已存在 | 拒绝，并说明撞上了哪个标签 |
| 输入里有逗号 | 拒绝，提示改用「粘贴」 |
| 改成另一个合法的标签 | 允许（`long hair` → `twintails`）——你敲了新名字就该用新名字 |

编辑中切换图片会**放弃**这次编辑（不写入），因为列表已经被另一张图的内容换过了。

## 翻译

| 快捷键 | 作用 |
|---|---|
| `Ctrl+Enter` | 翻译中文描述并追加到提示词末尾 |
| `Ctrl+Shift+T` | 模型补译标签的中文释义（只对词库查不到的标签生效） |

> 这两个是不同的东西：`Ctrl+Enter` 翻的是**中文描述 → 英文散文**（写进提示词），
> `Ctrl+Shift+T` 补的是**标签的中文注释**（只显示，不写进提示词）。

## 视图

| 快捷键 | 作用 |
|---|---|
| `Ctrl+0` | 恢复默认布局（三栏回到 2:2:3） |
| 双击分隔条 | 同上 |

## 预览窗口

| 快捷键 | 作用 |
|---|---|
| `空格` / 双击列表项 | 打开预览 |
| `←` / `→` | 上一张 / 下一张（主窗口跟着切换） |
| `Ctrl+滚轮` | 缩放；手动缩放后窗口大小变化不再自动适应 |
| `Ctrl+0` | 适应窗口 |
| `Esc` | 关闭预览窗口 |

---

> **注意**：`Ctrl+0` 用的是主键盘数字 0。笔记本上若 `0` 需要配合 `Fn`，这个组合可能不触发——那种情况下用菜单「视图 → 恢复默认布局」，或直接双击分隔条。
