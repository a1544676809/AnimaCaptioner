# 写标签模式

> 同一个程序里的第二块界面：**从零组装一段提示词，`Ctrl+S` 复制走**，供生图时用。
> 它和标注模式共用中栏、右栏和全部词库能力，只换了左栏、菜单和「主操作」。

## 为什么不是一个单独的 exe

因为要复用的正是这个程序的主体：词库校验、大类分段、`Tab` 补全、标签搜索、
中英对照、中文 → 英文翻译、大类配色、提示词解析与着色——这些**本来就不读当前图片**，
它们只吃「当前这段提示词」。实测所有标签操作（上移、删除、校验、规范、模型补译、粘贴）
没有一处碰当前图片，唯一耦合的只有「从哪个文件读、写回哪个文件」。

所以两个模式共用一份控件和一份代码，差异收敛成四件事：

| | 标注模式 | 写标签模式 |
|---|---|---|
| 左栏 | 图片列表 | 提示词库（历史 + 预设） |
| 当前文档 | 训练集里的一张图 → `.txt` | 内存里的一段草稿 → 提示词库 |
| 主操作（`Ctrl+S`） | 写回同名 `.txt` | 复制整行到剪贴板 |
| 菜单 | 浏览 / 标签 / 工具 | 提示词 / 标签 / 工具 |

拆成两个 exe 的代价是两份约 40 MB 输出、`settings.json` 的互相覆盖、
以及 `.pri` 资源那套打包坑；收益只是省掉上面这张表里的分派。

## 怎么进

- 菜单「**模式 → 写标签模式**」
- `Ctrl+M` 在两个模式之间来回切
- 程序会记住上次停在哪个模式，下次启动直接回到它

命令行的 `--draft` 可以直接以写标签模式启动，用于排查问题。

## 左栏：提示词库

历史与预设**同一个库**，用「钉住」区分——它们本质是同一种东西（一段提示词正文），
只是保留策略不同。

| 项 | 规则 |
|---|---|
| 复制即入库 | 按 `Ctrl+S` 复制走时自动记一条，这是"我现在在用这段提示词"最可靠的信号 |
| 按正文去重 | 正文相同就是同一条，只累加使用次数并顶到最前，不会刷出几十份副本 |
| 历史上限 | 300 条，超了丢**最旧的未钉住**条目 |
| 预设 | 钉住的条目**永不被上限清掉**。「清空历史」也只清未钉住的 |
| 标题 | 你没命名过就按正文派生，并**跳过质量/元信息/年代/安全这类样板前缀**——否则一堆条目的标题会长得一模一样 |
| 单击 | 载入这条提示词（载入前当前的草稿先落库） |
| 右键 | 钉为预设 / 重命名 / 从库里删除 |
| 过滤框 | 标题或正文包含关键词，大小写不敏感 |

存储位置：`%LocalAppData%\AnimaCaptioner\prompts.json`。

> **为什么不塞进 `settings.json`**：那是配置，而这是会随使用增长的数据。
> `settings.json` 的保存是**整份内存对象覆盖写**，把历史塞进去等于每复制一次提示词
> 就重写一遍全部设置。

## 新建提示词从哪开始

不是全空，而是官方推荐的生图前缀：

```text
masterpiece, best quality, score_7, safe
```

它同时是演示「质量 → 安全」这个子序（见 [标签顺序与分段](04-tag-order.md)）。

## 按热度自动排

菜单「标签 → 按热度自动排段内顺序」，**只在写标签模式出现**。

它按**训练集里的平均相对位置**给一般标签排序（`Core/VocabDb.cs` 的 `Arrange`），
头部四类则回到官方段序。这正是"从零组装"需要的：手边没有已经排好的顺序可参考。

标注模式里刻意**没有**这一项——那边的人在手动调段内顺序，自动重排会把调好的丢
（见 [标签顺序与分段](04-tag-order.md) 里"段内顺序原样保留"那条）。

> 提示词库为空、训练集读不到时也能用：它只是把"未知标签"统一放到末尾，再按字母排。

## 状态栏报什么

写标签模式下，状态栏左格报**这段提示词能不能用**：

```text
4 tags · ≈13 tokens · 安全 safe
```

- **tags** 与 token 估算来自 `PromptText`，与左栏列表、中栏用的是同一个口径
  （列表说没超、状态栏说超了这种事不该发生）。
- 超过 512 token 会直接标出来：训练器在 512 处**静默截断**，而丢掉的正好是排在末尾的散文。
- **安全档位**同时报「你写了什么」和「按判据该是什么」，两者不一致时带 `⚠`。
  这个判断在标注模式里要点「校验」才看得到，生图时更需要它随时在。

右格报词数与字符数。

## 复制走的是原文

`Ctrl+S`（以及菜单项和右下角按钮）复制的是**提示词框里的原文**，不是重新拼一遍——
你在框里手改过的标点、空格、权重写法都会原样带走。

底部还有「翻译并追加」在用，两个模式是一样的。

## 写标签模式碰不到训练集

- 这个模式下 `Ctrl+S` 不会写任何 `.txt`。
- 图片列表、「打开训练集」、上一张/下一张（含 `Alt+←` / `Alt+→`）都已隐藏或屏蔽，
  「最近打开」即使点了也只会重载图片列表，不会顶掉你正在写的草稿。
- 关窗口时当前草稿会自动落库，不会丢。

## 存哪、能不能搬

| 文件 | 内容 |
|---|---|
| `%LocalAppData%\AnimaCaptioner\prompts.json` | 提示词库（历史 + 预设） |
| `%LocalAppData%\AnimaCaptioner\settings.json` | 上次的模式、两个模式各自的分栏比例等 |
