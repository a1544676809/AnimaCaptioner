# 编辑帮助文档

> 这篇讲的是**用户文档**（`docs/` 顶层那些 `.md`）怎么写——格式约定、支持的语法、
> 图片与链接规则。它本身放在 `docs/dev/` 里，因为它讲的是文档系统怎么运作，
> 用户不需要知道。
>
> 帮助页的正文是磁盘上的 Markdown 文件，改完**不必重新编译，也不必重启程序**，
> 点工具栏的「重新载入」即可看到改动。

## 文件在哪

随程序分发的是**仓库里 `docs/` 顶层的 `.md`**，构建时被拷到 exe 同级：

```text
E:\source\repos\AnimaCaptioner\docs\01-shortcuts.md      ← 源（改这里）
                                     \02-interface.md
                                     \11-write-tag-mode.md
                                     \dev\               ← 本目录，不分发
E:\source\repos\AnimaCaptioner\bin\...\win-x64\docs\     ← 分发出去的副本
```

点帮助窗口工具栏的「**打开文档目录**」打开的是**分发出去的那一份**（exe 同级），
帮助窗口底部也会显示这个路径。

## 直接改就行

1. 在仓库的 `docs/` 里编辑任意 `.md`（用记事本、VS Code 都行）
2. 重新构建，让改动进到 exe 同级的 `docs`
3. 回到帮助窗口，点「**重新载入**」（或按 `F5`）

> 如果只是想**临时**看效果，也可以直接改 exe 同级那份 `docs`，点「重新载入」立即生效，
> 不必重启程序——但**重新构建会用仓库版本覆盖它**。长期改动一定要改仓库里的源。

## 文件格式

每个 `.md` 文件是一个**模块**，在左侧目录里占一项。

```markdown
# 模块标题

> 一句话摘要，显示在标题下面（可选）。

正文从这里开始……
```

- **第一行非空行**若是 `# 标题`，就作为目录里的模块名；否则退回用文件名
- 紧随标题的 `> 引用块`作为摘要，同时会从正文里摘掉（避免标题显示两次）
- 摘要里不要用 Markdown 标记——它是纯文本，`**加粗**` 会原样露出星号
- 文件名前缀的数字决定目录顺序：`01-`、`02-` …
- **开头不能加 HTML 注释**：`SplitHeader` 取第一个非空行当标题，注释会让标题退化成
  文件名；而渲染器刻意把 HTML 块当代码块原样显示（静默丢弃会让问题查不出来），
  于是那行注释还会直接显示在正文里

## 支持的 Markdown

| 语法 | 渲染为 |
|---|---|
| `# 标题` ~ `#####` | 分级标题（一级带强调色底线） |
| 段落 | 可选中复制的文本 |
| `**粗体**`、`*斜体*`、`~~删除线~~` | 对应样式 |
| `` `行内代码` `` | 等宽字体 |
| ` ```代码块``` ` | 带边框的等宽块，横向可滚动 |
| `- 列表`、`1. 列表` | 列表（可嵌套） |
| `- [x] 任务` | ☑ / ☐ 复选框 |
| `> 引用` | 左侧竖线 + 淡底 |
| 表格 | 真正的列对齐 |
| `[文字](链接)` | 站内 `.md` 链接在窗口内跳转；外链交给系统浏览器 |
| `![图](相对路径.png)` | 只加载 **docs 目录内**的本地图片 |

## 几个约定

- **外链**用系统默认浏览器打开，不在窗口内嵌
- **图片**只加载 docs 目录下的本地文件。`http://` 开头的联网图片**不加载**——帮助页要能离线看
- **站内链接按文件名解析**，不看目录：`[翻译](05-translation.md)` 会切到模块 id `translation`。
  所以链接写文件名即可，写 `../05-translation.md` 也一样能找到
- 图片相对路径按**当前 `.md` 文件所在目录**解析，可以建子目录分类放图。
  但 `ResolveAsset` 会把解析结果限制在 `docs/` 之内（`../` 出不去），
  所以**图片必须放在 `docs/` 底下**——放在 `docs/dev/` 里的文档即便引用了图片也不会渲染
  （它本来也不进帮助窗口）

## 加载出问题时

任何问题（文件读不了、Markdown 解析失败、图片找不到）都**不会**让帮助页挂掉——问题会收集成一条提示显示在正文末尾，其余内容照常显示。

帮助页本身挂掉是最糟的结果，因为用户正是来看怎么排错的。
