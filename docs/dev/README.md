> `docs/` 顶层、不递归，构建时的分发 glob 也只收顶层 `docs\*.md`。
>
> 写给用户看的那些在上级目录 `docs/` 里，那才是随程序分发的帮助文档。

## 帮助文档是怎么加载的

`docs/` 里**每个 `.md` 文件是帮助窗口左侧目录的一项**。加载走
`Core/HelpDocs.Load`（纯逻辑、不依赖 UI 类型，所以能被 net10 回归直接编译）：

- 目录：`<exe>\docs`（`HelpDocs.Dir`）
- 排序：文件名开头的数字（`01-`、`02-` …），没有数字的排最后
- 标题：正文第一行非空行的 `# 标题`；没有就退回文件名
- 摘要：紧接标题的 `> 引用块`，会从正文里摘掉（避免标题显示两次）
- 模块 id：文件名去掉 `NN-` 前缀与扩展名，用来记住"上次看的是哪一页"

`LICENSE` 不带 `.md` 后缀，所以不会被当模块加载；它由 csproj 单独列为分发内容。

## 加一个用户文档模块

在 `docs/` 里新建 `.md`（**不是这里**），文件名给个数字前缀，例如
`12-troubleshooting.md`。点帮助窗口的「重新载入」即可看到，顺序按前缀数字排。

## 删掉一篇文档时

`docs/` 的计数写在两个地方，别忘了同步：根 `README.md` 的「目录」树，以及
「许可」一节里 `docs/` 的许可范围说明。
