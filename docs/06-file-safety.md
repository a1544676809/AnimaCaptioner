# 写入文件的安全性

> 这个工具直接改你的训练集 `.txt`。这一节说明它凭什么不会弄坏文件。

## 字节风格严格沿用原文件

保存时严格保持原文件的字节风格：

| 项 | 值 |
|---|---|
| BOM | 无 |
| 行尾 | `CRLF` |
| 结尾换行 | 有，且只有一个 |
| 标签分隔符 | `", "`（逗号 + 空格） |

新建文件也用同一套风格，不会出现"新文件和老文件不一样"的情况。

## 内容没变就不碰文件

如果保存前后内容完全一致，**不会写盘**。这样不会无谓地改动文件的修改时间。

## 自然语言那段原样写回

自然语言那段不会被当成标签重排。这一点有过一个真实缺陷：早期版本的保存路径只写标签，带散文的提示词一存，那段英文就**整段消失**，而列表上看不出任何变化。现在保存写的是拼好的整行，回归测试里还留了一个**反例**，专门证明旧写法确实会丢。

## 回归测试

工具自带四套回归，改代码后都会跑：

| 套件 | 验什么 |
|---|---|
| `parity` | 126 项与已验证的 Python 实现对拍 |
| `roundtrip` | 53 个 caption **逐字节**往返一致 |
| `sections` | 分类规则对现有 caption 是恒等变换（53/53） |
| `prose` | 标签 / 散文切分规则，含保存不丢散文的反例 |

其中 `sections` 最有价值：它会直接指出**哪个标签会被挪到哪一段**。靠肉眼看 2335 个标签是查不出分类规则改错的。
