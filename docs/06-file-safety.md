# 写入文件的安全性

> 这个工具直接改你的训练集 `.txt`。这一节说明它凭什么不会弄坏文件。

## 字节风格严格沿用原文件

保存时严格保持原文件的字节风格：

| 项 | 值 |
|---|---|
| BOM | 无 |
| 行尾 | `CRLF` |
| 结尾换行 | 有，且只有一个 |
| 标签分隔符 | `", "`（逗号 + 空格） |

新建文件也用同一套风格，不会出现"新文件和老文件不一样"的情况。

## 内容没变就不碰文件

如果保存前后内容完全一致，**不会写盘**。这样不会无谓地改动文件的修改时间。

## 空提示词不会建出空文件

在一张还没标注的图上停留再切到下一张，不会凭空生成一个空的 `.txt`——只有真的写进内容才会建文件。

## 自然语言那段原样写回

自然语言那段不会被当成标签重排——保存写的是拼好的整行，所以带散文的提示词存下来，那段英文仍在原处。
