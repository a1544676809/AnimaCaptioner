# 界面与布局

> 三栏各是什么、分隔条怎么用、布局怎么记住。

## 两个模式

程序有两个模式，用菜单「模式」或 `Ctrl+M` 切换，**上次停在哪个模式会记住**：

| 模式 | 干什么 | 主操作（`Ctrl+S`） |
|---|---|---|
| **标注模式** | 给训练集里的图片写 caption | 写回同名 `.txt` |
| **写标签模式** | 从零组装一段提示词，生图时用 | 复制整行到剪贴板 |

两个模式**共用中栏和右栏**（标签列表、提示词原文、翻译器完全一样），
差异只在左栏、菜单和主操作。写标签模式详见 [写标签模式](11-write-tag-mode.md)。

## 撤销与重做

菜单「编辑」里是撤销 / 重做两项，快捷键 `Ctrl+Z` / `Ctrl+Y`。菜单文案会写明
下一步退掉的是哪个操作（「撤销（添加标签）」），两项按栈的现状自动变灰。

撤销的是**当前文档**：标签的增删改移、粘贴、规范化、重排、翻译、清空都能退。
它只改内存、不写文件；换图片或换提示词时历史清空。步数上限在
「设置 → 编辑 → 最大撤销步数」（默认 100，0 = 关闭）。详见[快捷键](01-shortcuts.md)。

## 三栏（标注模式）

```text
┌──────────┬────────────┬──────────────────────┐
│ 图片列表  │  tag 列表   │  提示词原文（写入文件）  │
│          │            │  ──────────────────  │
│ 单击：读取 │ 分段显示    │  中文描述 → 英文自然语言 │
│ 双击：预览 │ 可拖动排序  │  （翻译器）            │
└──────────┴────────────┴──────────────────────┘
```

- **左栏**是图片列表。单击某一行读取它的 tag，双击（或按空格）打开独立预览窗口。
  每行显示缩略图、文件名、标注状态徽标和标签数。
  **写标签模式下这一栏换成提示词库**（历史 + 预设，带过滤框）。
- **中栏**是 tag 列表，按官方大类分段显示，每段一个该类别颜色的框。两个模式共用。
- **右栏**上面是**提示词原文**（标注模式写入 `.txt`，写标签模式复制走，标题栏会写明），
  下面是中文描述 → 英文自然语言的**翻译器**。两个模式共用。

## 标签行的两种操作

**双击标签**就地改名。输入框里可以直接打字，**候选列表会自动展开**，`Tab` 补全
（再按切下一个，`Shift+Tab` 往回），点候选直接采用，`Enter` 提交 / `Esc` 取消 /
点别处提交。

中栏顶部的**添加标签**框是同一套用法：打中文或英文都会给候选，`Tab` 补全，
`Enter` 加进去。加完会按大类归位，所以新标签出现在它该在的段里，而不是甩到末尾。

**改完名之后，选中和视线都留在那一行**：它仍然被选中，列表也不会跳回顶部；
如果改名让它跨到了别的大类、位置挪出了视野，列表会跟着翻一页，让它停在最上或
最下一行——和上移/下移时的行为一致。

> 补全的两个细节：**按 `Tab` 后框里是什么、`Enter` 加的就是什么**；而**一个已经
> 合法的标签第一次按 `Tab` 不会被改掉**，只会在状态栏报第几格。完整规则见
> 「快捷键 → 输入框补全」。

**右键标签**打开功能菜单：

| 菜单项 | 说明 |
|---|---|
| 复制 | 按列表可见顺序复制选中标签，逗号分隔。多选时复制多个 |
| 粘贴 | 把剪贴板文本解析成标签追加。换行会折成逗号，所以从表格里复制一列也行 |
| 编辑标签… | 同双击（只在恰好选中一个时可用） |
| 翻译 / 规范化 | 中文 → 英文标签、去下划线、旧别名 → 正典名、补画师 `@` |
| 模型翻译 | 给**词库查不到中文**的标签补一个释义（结果是推断，会标出来） |
| 上移 / 下移 | 只在本大类内部移动。列表位置跟着标签走，标签被移出视口时列表翻一页让它贴边 |
| 删除 | 删除选中标签 |
| 校验整行 | 对整行做一次词库校验 |

右键会先把被点的那行选中（若它原本没被选中），所以菜单操作的永远是你看的那一行。
点在空白处则保留原有选中，菜单对整批生效。

> 「翻译 / 规范化」和「模型翻译」是两件事：前者**改标签写法**（写进提示词），
> 后者只**补一条中文注释**（只显示，不写进提示词）。词库已有官方释义的标签，
> 模型翻译那一项会变灰。

## 标签右侧的中文释义

中栏每行右边是中文释义。**两种来源在界面上是分开的**，因为可信度不同：

| 样子 | 来源 | 可信度 |
|---|---|---|
| 灰色，如 `微笑` | 词库（Danbooru 对照表） | 官方 |
| **橙色 + `≈`**，下面一行小字 `模型译 · 非官方` | 模型推断 | 可能错，请自行判断 |

模型译文的缓存位置：`%LocalAppData%\AnimaCaptioner\model-gloss.json`。
它**不会**写回词库，也不会覆盖官方释义。

> **粘贴是"解析"而不是"照搬"**：`print yukata` 会被规范化成 `print kimono`，
> 重复的会跳过，而一段英文散文会被识别出来并拒绝——提示你改用右上的提示词原文。
> 详见「提示词格式」。

## 分隔条

三栏之间可以拖动分隔条调整宽度。**双击分隔条**或按 `Ctrl+0` 回到默认比例——
标注模式是 `2:2:3`，写标签模式是 `1.4:2:3`（那边左栏是列表，不需要图片列表那么宽）。

分栏比例会记住，下次启动沿用。**两个模式各存一套**：它们的分栏语义不同
（图片 / 标签 / 提示词 vs 提示词库 / 标签 / 提示词）。

> 提醒：中栏最窄只能到约 240 DIP——再窄下去底部的「上移 / 下移 / 删除 / 校验」四个按钮就会被裁掉。

## 底部状态栏

标注模式显示当前是第几张 / 共几张、数据集标注统计、以及有几个标签存在校验问题。

写标签模式显示的是另一套口径：**token 预算 + 安全档位 + 词数/字符数**
（见 [写标签模式](11-write-tag-mode.md)）。

## 配色

十项各自有一个颜色，可在**设置 → 标签大类配色**里改：

| 大类 | 含义 |
|---|---|
| 质量 | `masterpiece`、`best quality`、`score_7` 这类 |
| 元信息 | `highres`、`absurdres`、`jpeg artifacts` |
| 年代 | `year 2025`、`newest`、`recent` |
| 安全 | `safe`、`sensitive`、`nsfw`、`explicit` |
| 人物数量 | `1girl`、`solo`、`2boys` |
| 角色 | 具体角色名 |
| 作品 | 系列 / 作品名 |
| 画师 | 画师标签（带 `@` 前缀） |
| 一般标签 | 其余全部 |
| 自然语言 | 提示词里那段英文散文 |

> 官方模型卡把前四类写成同一个方括号 `[quality/meta/year/safety tags]`，
> 并说段内顺序任意。本工具把它们拆成四段显示与着色，理由是安全词有自己独立的
> 档位校验、且官方推荐前缀 `masterpiece, best quality, score_7, safe` 正是这个
> 子序。详见 [标签顺序与分段](04-tag-order.md)。

配色存在 `settings.json` 里，改完立刻反映到列表。
