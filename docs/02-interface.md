# 界面与布局

> 三栏各是什么、分隔条怎么用、布局怎么记住。

## 三栏

```text
┌──────────┬────────────┬──────────────────────┐
│ 图片列表  │  tag 列表   │  提示词原文（写入文件）  │
│          │            │  ──────────────────  │
│ 单击：读取 │ 分段显示    │  中文描述 → 英文自然语言 │
│ 双击：预览 │ 可拖动排序  │  （翻译器）            │
└──────────┴────────────┴──────────────────────┘
```

- **左栏**是图片列表。单击某一行读取它的 tag，双击（或按空格）打开独立预览窗口。
  每行显示缩略图、文件名、标注状态徽标和标签数。
- **中栏**是 tag 列表，按官方大类分段显示，每段一个该类别颜色的框。
- **右栏**上面是写入 `.txt` 的**提示词原文**，下面是中文描述 → 英文自然语言的**翻译器**。

## 标签行的两种操作

**双击标签**就地改名。输入框里可以直接打字，**候选列表会自动展开**，`Tab` 补全
（再按切下一个，`Shift+Tab` 往回），点候选直接采用，`Enter` 提交 / `Esc` 取消 /
点别处提交。

中栏顶部的**添加标签**框是同一套用法：打中文或英文都会给候选，`Tab` 补全，
`Enter` 加进去。加完会按大类归位，所以新标签出现在它该在的段里，而不是甩到末尾。

> 补全的两个细节：**按 `Tab` 后框里是什么、`Enter` 加的就是什么**；而**一个已经
> 合法的标签第一次按 `Tab` 不会被改掉**，只会在状态栏报第几格。完整规则见
> 「快捷键 → 输入框补全」。

**右键标签**打开功能菜单：

| 菜单项 | 说明 |
|---|---|
| 复制 | 按列表可见顺序复制选中标签，逗号分隔。多选时复制多个 |
| 粘贴 | 把剪贴板文本解析成标签追加。换行会折成逗号，所以从表格里复制一列也行 |
| 编辑标签… | 同双击（只在恰好选中一个时可用） |
| 翻译 / 规范化 | 中文 → 英文标签、去下划线、旧别名 → 正典名、补画师 `@` |
| 模型翻译 | 给**词库查不到中文**的标签补一个释义（结果是推断，会标出来） |
| 上移 / 下移 | 只在本大类内部移动 |
| 删除 | 删除选中标签 |
| 校验整行 | 对整行做一次词库校验 |

右键会先把被点的那行选中（若它原本没被选中），所以菜单操作的永远是你看的那一行。
点在空白处则保留原有选中，菜单对整批生效。

> 「翻译 / 规范化」和「模型翻译」是两件事：前者**改标签写法**（写进提示词），
> 后者只**补一条中文注释**（只显示，不写进提示词）。词库已有官方释义的标签，
> 模型翻译那一项会变灰。

## 标签右侧的中文释义

中栏每行右边是中文释义。**两种来源在界面上是分开的**，因为可信度不同：

| 样子 | 来源 | 可信度 |
|---|---|---|
| 灰色，如 `微笑` | 词库（Danbooru 对照表） | 官方 |
| **橙色 + `≈`**，下面一行小字 `模型译 · 非官方` | 模型推断 | 可能错，请自行判断 |

模型译文的缓存位置：`%LocalAppData%\AnimaCaptioner\model-gloss.json`。
它**不会**写回词库，也不会覆盖官方释义。

> **粘贴是"解析"而不是"照搬"**：`print yukata` 会被规范化成 `print kimono`，
> 重复的会跳过，而一段英文散文会被识别出来并拒绝——提示你改用右上的提示词原文。
> 详见「提示词格式」。

## 分隔条

三栏之间可以拖动分隔条调整宽度。**双击分隔条**或按 `Ctrl+0` 回到默认的 2:2:3 比例。

分栏比例会记住，下次启动沿用。

> 提醒：中栏最窄只能到约 240 DIP——再窄下去底部的「上移 / 下移 / 删除 / 校验」四个按钮就会被裁掉。这个下限是按按钮行的实际宽度量出来的，不是随手定的。

## 底部状态栏

显示当前是第几张 / 共几张、标签总数、以及有几个标签存在校验问题。

## 配色

七个大类各自有一个颜色，可在**设置 → 标签大类配色**里改：

| 大类 | 含义 |
|---|---|
| 质量 / 元信息 / 年 / 安全 | `masterpiece`、`score_7`、`safe`、`explicit` 这类 |
| 人物数量 | `1girl`、`solo`、`2boys` |
| 角色 | 具体角色名 |
| 作品 | 系列 / 作品名 |
| 画师 | 画师标签（带 `@` 前缀） |
| 一般标签 | 其余全部 |
| 自然语言 | 提示词里那段英文散文 |

配色存在 `settings.json` 里，改完立刻反映到列表。
