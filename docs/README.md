# 帮助文档模块

这个目录里的每个 `.md` 文件是帮助窗口左侧目录的一项。**文档随程序分发**，运行时直接读这里，所以改完点「重新载入」即可生效，不必重启程序。

| 文件 | 模块 |
|---|---|
| `01-shortcuts.md` | 快捷键 |
| `02-interface.md` | 界面与布局 |
| `03-prompt-format.md` | 提示词：标签 + 自然语言 |
| `04-tag-order.md` | 标签顺序与分段 |
| `05-translation.md` | 翻译是怎么做的 |
| `06-file-safety.md` | 写入文件的安全性 |
| `07-editing-docs.md` | 编辑本文档 |
| `08-safety-ratings.md` | 安全标签的边界 |
| `09-tags-vs-prose.md` | 标签还是自然语言 |

## 怎么改

直接编辑这里的 `.md`，回到帮助窗口点「**重新载入**」（`F5`）即可。

注意：这个目录随程序分发，**重新构建时会被仓库版本覆盖**。想把改动长期留下来，请改仓库里的 `E:\source\repos\AnimaCaptioner\docs`。

详细的格式约定、支持的语法、图片和链接规则，见 [编辑本文档](07-editing-docs.md)。

## 加一个新模块

在这里新建一个 `.md`，文件名给个数字前缀（例如 `08-troubleshooting.md`），点「重新载入」即可。顺序按前缀数字排。

## 本文件

`README.md` 没有数字前缀，所以会排在目录最后。不想让它出现就直接删掉，不影响程序。
