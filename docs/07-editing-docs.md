# 编辑本文档

> 帮助页的正文是磁盘上的 Markdown 文件，改完**不必重新编译，也不必重启程序**。
> 点工具栏的「重新载入」即可看到改动。

## 文件在哪

帮助文档随程序分发，就在 **exe 同级的 `docs` 目录**里：

```text
<程序目录>\docs\01-shortcuts.md
              \02-interface.md
              \...
```

点工具栏的「**打开文档目录**」可以直接在资源管理器里打开它。帮助窗口底部也会显示这个路径。

## 直接改就行

1. 在 `docs` 里编辑任意 `.md`（用记事本、VS Code 都行）
2. 回到帮助窗口，点「**重新载入**」（或按 `F5`）
3. 改动立即显示，**不用重启程序**

> 唯一要注意的是**重新构建程序**时会用仓库里的版本覆盖 `docs`——因为它是随程序分发的。
> 想把改动留下来，改仓库里的 `E:\source\repos\AnimaCaptioner\docs`，或者把改动另存一份。

## 文件格式

每个 `.md` 文件是一个**模块**，在左侧目录里占一项。

```markdown
# 模块标题

> 一句话摘要，显示在标题下面（可选）。

正文从这里开始……
```

- **第一行非空行**若是 `# 标题`，就作为目录里的模块名；否则退回用文件名
- 紧随标题的 `> 引用块`作为摘要，同时会从正文里摘掉（避免标题显示两次）
- 摘要里不要用 Markdown 标记——它是纯文本，`**加粗**` 会原样露出星号
- 文件名前缀的数字决定目录顺序：`01-`、`02-` …

## 支持的 Markdown

| 语法 | 渲染为 |
|---|---|
| `# 标题` ~ `#####` | 分级标题（一级带强调色底线） |
| 段落 | 可选中复制的文本 |
| `**粗体**`、`*斜体*`、`~~删除线~~` | 对应样式 |
| `` `行内代码` `` | 等宽字体 |
| ` ```代码块``` ` | 带边框的等宽块，横向可滚动 |
| `- 列表`、`1. 列表` | 列表（可嵌套） |
| `- [x] 任务` | ☑ / ☐ 复选框 |
| `> 引用` | 左侧竖线 + 淡底 |
| 表格 | 真正的列对齐 |
| `[文字](链接)` | 站内 `.md` 链接在窗口内跳转；外链交给系统浏览器 |
| `![图](相对路径.png)` | 只加载 **docs 目录内**的本地图片 |

## 几个约定

- **外链**用系统默认浏览器打开，不在窗口内嵌
- **图片**只加载 docs 目录下的本地文件。`http://` 开头的联网图片**不加载**——帮助页要能离线看
- **相对链接**指同目录的另一个 `.md`，会切换模块，例如 `[翻译](05-translation.md)`
- 图片相对路径按**当前 `.md` 文件所在目录**解析，可以建子目录分类放图

## 加载出问题时

任何问题（文件读不了、Markdown 解析失败、图片找不到）都**不会**让帮助页挂掉——问题会收集成一条提示显示在正文末尾，其余内容照常显示。

帮助页本身挂掉是最糟的结果，因为用户正是来看怎么排错的。
